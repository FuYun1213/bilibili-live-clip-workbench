直播切片工作台（分享版）
==========================

快速开始
1. 解压整个压缩包，不要直接在压缩包内运行。
2. 双击“首次安装.cmd”，保持联网并等待依赖安装完成。
3. 建议安装 64 位 VLC；它用于审核台内嵌视频播放。
4. 双击“启动工作台.cmd”。
5. 在工作台内打开“扫码登录”，用哔哩哔哩客户端扫码并确认。

这个分享包包含
- 当前直播切片台代码、界面、模板与公开人物配置。
- Windows 版 FFmpeg 和 FFprobe。
- 首次安装脚本与独立的 Python 3.12 环境入口。

这个分享包不包含
- 原作者的 Cookie、登录凭证或账号合集编号。
- 录播、弹幕、既有项目、审核素材和已完成视频。
- Whisper 模型和 Python 运行环境。

首次安装与磁盘空间
- 首次安装需要联网，Python/PyTorch 等依赖可能下载数 GB。
- 首次使用转写功能时，还会下载所选 Whisper 模型。
- 建议至少预留 15 GB 可用空间；录播和项目素材另算。

外部组件
- VLC（推荐）：https://www.videolan.org/vlc/
  用于工作台内嵌视频预览；未安装时仍可调用外部播放器。
- Codex CLI（自动选片流程需要）：https://learn.chatgpt.com/docs/codex/cli
  安装后需在朋友自己的账号中登录。手动流程不依赖自动选片。

登录与隐私
- 扫码成功后，Cookie 会写入当前 Windows 用户的私有应用数据目录，不会写进分享包。
- “创建 Cookie 模板”只创建空模板，不会覆盖可用凭证。
- 请勿分享首次运行后生成的 Cookie、项目目录或录播素材。

合集设置
- 分享版保留合集标题用于自动匹配，但已移除原账号 season_id/section_id。
- 朋友扫码登录自己的账号后，匹配不到时可由工作台按标题创建或重新绑定合集。

故障排查
- 启动提示未安装：重新运行“首次安装.cmd”。
- 内嵌视频不显示：安装 64 位 VLC 后重启工作台。
- 自动选片显示“等待 Codex”：安装并登录 Codex CLI，或在设置中选择 codex.exe/codex.cmd。
- 首次转写较慢：通常正在下载模型；不要关闭安装或工作台窗口。
